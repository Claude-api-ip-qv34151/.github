<p>买住宅 IP 最怕的是问错问题。多数人开口就问「多少钱一条」，对方给个区间，你也没法判断贵在哪、便宜又省掉了什么。更有效的做法是把需求翻译成一组参数，逐项问清取值和口径，再对比报价。这篇就是一份参数说明书：出口侧四项、会话侧三项、计费侧三项、验收一项，共十一个参数，每个写清怎么问、合理取值在哪、取值不清会带来什么后果。适合准备采购、需要跟服务商把条件谈明白的人直接拿去当提问清单。</p>

<h2>二、出口侧：四项参数决定线路的「身份」</h2>
<p>这四项决定的是线路在平台眼里像什么。它们不体现在价格表上，但直接决定使用体验，问的时候要具体到能验证的层面。</p>
<img src="/tp.png" alt="Claude API 住宅IP 采购参数与出口归属核验项目示意">
<h3>ASN 属性：要号码，不要形容词</h3>
<p>别问「是不是住宅」，直接问「这条线的 ASN 是多少」。拿到 ASN 号之后自己查：<code>ipinfo.io</code> 会显示 ASN 对应的组织名，组织名应该是当地宽带运营商。如果对方给不出 ASN，或者给的号码查出来是托管商，那就没有继续谈的必要。</p>
<h3>池子规模：问总数，也问可用数</h3>
<p>「我们有几百万 IP」这类回答参考价值不大，因为全球池和你所在地区能分到的数量是两回事。要问的是：这个城市当前可分配的独立 IP 有多少，其中有多少是近期未被高频使用的。后一个数字一般不会给准确值，但对方的回应方式能说明问题。</p>
<h3>段分散度：跨 /24 才算分散</h3>
<p>这是最容易被忽略的一项。给你十个不同的 IP，但全在 203.0.113.0/24 里，平台侧看到的仍是一段地址。要明确要求在分配时跨 /24 段，最好跨两个以上网段。这条写进合同或者订单备注里，事后有依据。</p>
<h3>归属稳定性：租期内不变才算独享</h3>
<p>有些方案在租期内会做 IP 回收重分配，尤其是按量计费的共享池。要问清：我这条线在租期内会不会变 IP，什么情况下会变，变了是否提前通知。对老号来说，出口稳定比出口多更重要。</p>

<h2>三、会话侧：三项参数决定跑得稳不稳</h2>
<p>出口对了，还得看会话层支持到什么程度。这三项在报价单上通常不写，但不问清楚，跑长任务时会集中暴露。</p>
<h3>并发上限</h3>
<p>问的是单账号允许的并发连接数，不是整条线的总并发。有的方案在线路层不限制，但在账号层做了连接数控制，超出就排队或者重置。日常对话 2 到 4 个并发够用，批量任务按实际压测结果定。</p>
<h3>保活与空闲断开</h3>
<p>直接问「长连接最长能挂多久，空闲多久会被断开」。如果对方答不上来，就自己测：挂一条连接，每 30 秒发一次心跳，看能撑多久。撑不过一小时且没有明确说明的，跑长任务要谨慎。</p>
<h3>协议支持</h3>
<p>HTTP 代理够用于大部分场景，但如果你要在容器里做透明代理或者跑非 HTTP 协议，就需要 SOCKS5。UDP 支持视业务而定，多数 API 调用用不上，但做实时语音类应用时要确认。</p>

<h2>四、计费侧：三项参数决定钱花得值不值</h2>
<p>计费口径的差异，能让同样的用量差出两三倍成本。三项里最关键是粒度。</p>
<h3>计费粒度与最小单位</h3>
<p>按小时计费的最小单位可能是 1 小时，也可能是 24 小时；按天计费的可能是自然日，也可能是滚动 24 小时。差别在于：晚上 11 点开通，自然日算法当天就结束，滚动算法能用到第二天晚上。这个细节在短期试用阶段影响很大。</p>
<h3>流量口径</h3>
<p>问清上下行是否都计、重试产生的流量是否计、以及是否存在最低消费。长任务场景里重试流量占比不低，如果重试也计费，实际成本会比预估高出两成左右。</p>
<h3>停机规则</h3>
<p>暂停期间是否计费、恢复后 IP 是否保留、保留多久。这三条对淡旺季明显的业务影响最大。理想情况是暂停不计费且保留 IP 至少 7 天，这样淡季停一个月回来还能接着用原来的环境。</p>

<h3>打分之后怎么决策</h3>
<p>分数接近时，优先选出口稳定性高的那家。稳定性直接影响老号的存活，而纯净度可以靠换线补救，稳定性差则每次都要重建环境。这条经验在长期使用中反复被验证。</p>

<h2>常见问答</h2>
<h3>「独享」到底指什么？</h3>
<p>答：一定要问清。常见三种含义：一条线路一个客户、一个 IP 一个客户、或者只是不复用同一时刻。对老号来说，需要的是「一个账号固定一个出口 IP 且该 IP 不与其他客户共用」，采购时把这句原话写进订单备注。</p>
<h3>池子大就不会撞车吗？</h3>
<p>答：不一定。池子大只降低了概率，还要看分配策略是否跨段。同一 /24 段内即使 IP 不同，集中度高了仍有风险。所以除池子规模外，一定要问段分散度。</p>
<h3>按小时计费会不会更贵？</h3>
<p>答：单价通常更高，但总成本未必。短期试用、应急切换、淡季低频使用这三种场景，按小时往往更省。判断方法是用最近 14 天的日均使用时长去对比两种计费方式的月总价。</p>
<h3>换线次数有没有限制？</h3>
<p>答：多数方案有。常见是每月免费换一到三次，超出按次收费。这条要写进采购条件里，并且明确响应时限，否则线路出问题时会陷入等待。</p>
